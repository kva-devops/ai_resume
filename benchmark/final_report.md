# Финальная проверка улучшенного промпта

Проверены 25 новых синтетических резюме по той же рубрике: эталон `gpt-6-astra` через Codex и текущая модель приложения `gpt-4o-mini` через Proxy API с промптом v2.

| Метрика | Astra | GPT-4 Mini + v2 |
|---|---:|---:|
| Средний балл | 76.00 | 80.72 |
| Диапазон | 64–90 | 64–100 |
| Среднее расхождение | — | +4.72 |
| Сильное завышение (>5) | — | 12/25 |

В предыдущем прогоне среднее расхождение составляло **+15.44 балла**, а завышение наблюдалось в 49 из 50 случаев. В финальном прогоне расхождение снизилось до **+4.72 балла**, то есть промпт v2 заметно улучшил калибровку. Полного устранения завышения пока нет: остаются отдельные случаи по bonus-технологиям, Spring/backend и Java Core.

Подготовлена версия v3 с более строгой калибровкой 0–5, потолком для одного списка навыков, обязательным практическим контекстом для bonus-технологий и правилом «при сомнении — более низкий статус».
