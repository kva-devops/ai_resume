# Контур — оценка резюме по вакансии

Локальное браузерное приложение для рекрутера: формирует критерии из вакансии, позволяет подтвердить веса, извлекает текст из PDF/CSV, оценивает кандидатов через OpenAI-совместимый Proxy API и показывает проверяемые цитаты.

Отдельный пункт «Системный промпт» в боковом меню открывает экран администрирования: полный текст инструкции модели можно изучить, отредактировать и сохранить как новую версию. Изменения применяются только к последующим оценкам.

## Запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-app.ps1
```

После сообщения `Uvicorn running` откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Первый запуск устанавливает локальные зависимости и собирает интерфейс. Данные сохраняются в `app.db`, загруженные файлы — в `uploads/`.

## Proxy API

Сервер автоматически читает ключ из `ProxyApiKey.txt` в корне проекта. Файл исключён из Git и не отдаётся браузеру. Альтернативно можно создать `.env` по образцу `.env.example` и указать:

```env
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
```

## Поддерживаемые файлы

- Вакансия: текст, TXT или PDF с текстовым слоем.
- Резюме: PDF с текстовым слоем или CSV с заголовком и одной строкой кандидата.
- CSV-шаблон можно скачать прямо на вкладке «Кандидаты».

OCR не используется. PDF-сканы без извлекаемого текста отклоняются с понятным сообщением.
